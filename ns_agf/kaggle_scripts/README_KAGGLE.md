# 📤 Kaggle Training Scripts for NS-AGF

## Overview
This folder contains scripts to be **manually uploaded to Kaggle** for training the NS-AGF model.

### Why Kaggle?
- **GPU Access**: Kaggle provides free T4/P100 GPUs
- **No Local Training**: Your laptop cannot handle large-scale video dataset training
- **Workflow**: Train on Kaggle → Export weights → Download to local VS Code

---

## 🚀 Quick Start Guide

### Step 1: Prepare Your Kaggle Environment

1. **Create a new Kaggle Notebook**:
   - Go to https://www.kaggle.com/code
   - Click "New Notebook"
   - Choose "GPU T4 x2" accelerator (Settings → Accelerator)

2. **Upload Your Custom Dataset**:
   - Click "Add Data" → "Upload Dataset"
   - Upload your sign folders organized as:
     ```
     your-dataset/
       ├── sign1/
       │   ├── video1.mp4
       │   ├── video2.mp4
       ├── sign2/
       │   ├── video1.mp4
     ```
   - **No need for train/val split** - the script handles it automatically (80/20)

### Step 2: Upload Scripts

Copy the following files from this folder into your Kaggle notebook:

1. `preprocess_wlasl.py` - Data preprocessing
2. `train_agcn.py` - Training script
3. `export_model.py` - Model export script

### Step 3: Install Dependencies

In your Kaggle notebook, first cell:

```python
!pip install mediapipe einops scikit-learn
```

### Step 4: Run Training

Execute cells in order:

```python
# Cell 1: Preprocessing
%run preprocess_wlasl.py

# Cell 2: Training
%run train_agcn.py

# Cell 3: Export
%run export_model.py
```

### Step 5: Download Weights

After training completes:

1. Go to **Output** tab in Kaggle
2. Find `ns_agcn_bankassist.pth`
3. Click "Create New Model" or download directly
4. If creating model: Note the model handle (e.g., `yourname/ns-agcn-model`)

## 🔧 Configuration Options

### In `train_agcn.py`:

```python
# Modify these as needed
NUM_CLASSES = 100        # Number of sign language classes
BATCH_SIZE = 16          # Reduce if GPU OOM
NUM_EPOCHS = 50          # Increase for better accuracy
LEARNING_RATE = 0.001    # Adjust based on convergence
```

### Dataset Paths:

If using custom dataset, update paths in `preprocess_wlasl.py`:

```python
DATASET_PATH = "/kaggle/input/your-dataset-name/"
```

## 📊 Expected Training Time

- **WLASL 100 classes**: ~6-8 hours on T4
- **WLASL 2000 classes**: ~24-30 hours on T4
- **Custom 200 classes**: ~10-12 hours

## 🆘 Troubleshooting

### GPU Out of Memory
```python
# Reduce batch size in train_agcn.py
BATCH_SIZE = 8  # or even 4
```

### Import Errors
```python
# Add to first cell
import sys
sys.path.append('/kaggle/working')
```

